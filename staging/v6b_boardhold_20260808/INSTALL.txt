v6b boardhold STUDY-leak fix — staging 20260808
================================================

WHAT THIS FIXES (owner field report, top priority for this weekend):
The on-card "Dr Mario STOMPER vs YOU v6 (boardhold).nes" (3e7c6ed9) renders the
STUDY pause letters + next-pill preview sprites (OAM slots 32-40) over LIVE PLAY
every frame — the "flickers randomly and shows STUDY on top as if start is
pressed" defect. Root cause: the DRSTUDY2P hook wrote visible-Y STUDY sprites on
every play frame, wrongly assuming the base ROM's OAM rebuild would overwrite
them (R8712 only pads from the sprite high-water mark; in VS play the game owns
zero sprites, so nothing ever cleaned the slots). NOT a spurious START; NOT
DRHOLDBOARD. Fix commit 72a8628 / manifests bf9d86e on branch study2p-pause-gate
(dr-mario worktree), tag study2p-leak-fix-20260808.
